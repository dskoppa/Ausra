GitHub webhook setup

In the GitHub repository, open Settings → Webhooks → Add webhook. Choose application/json, paste this URL and secret, and select push events. The secret appears only now. Pushes sync the matching branch or tag. Choose an optional job or workflow trigger on the repository card; triggered runs always wait for admin approval.

GitHub must be able to reach this URL over public HTTPS. A localhost URL needs a reverse proxy and public hostname.

Recent deliveries
